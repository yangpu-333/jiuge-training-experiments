# 2026-11-10 CPT复现材料

从仓库根目录的[复现指南](../../REPRODUCE.md)开始。

- `tools/`：实测入口、RMSNorm/Triton、SwiGLU C++/CoreX、DP1状态组装及数值/恢复审计代码；`TOOLS_SHA256.json`绑定字节。
- `inputs/`：原模型来源、权重与tokenizer哈希、显式化后的配置、数据manifest和原数值门槛。大模型和语料从各自上游取得。
- `environment/`：实测厂商版本清单及公开环境模板；CoreX包由平台镜像提供，不用普通PyPI torch替代。
- `prepare.py`：核对固定上游、安装实验代码、生成全新运行目录和移除历史调度前置条件的控制器。默认只检查，`--install`才写入实验目录。
- `prepare_inputs.py`：校验模型原件、仅显式化默认配置，以及校验数据准备结果；不下载权重。
- 正式控制器的6次保存恢复预检：在正式计时前构建扩展并预热所有三臂的实际训练路径，预检结果不计入正式数据。

原测量代码保持原字节；新的运行目录和控制器差异写入`reproduction-adaptation.json`。重新运行不需要旧账号、历史损坏文件、优惠券或已过期的调度时限。新鲜环境脚本在发布时完成语法、依赖和离线检查，**未在本次发布中再执行一整轮GPU实验**。
